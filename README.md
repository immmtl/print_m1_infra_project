# Проверка паролей

Учебный проект на FastAPI для проверки надёжности паролей и генерации случайных паролей.

## Запуск

Нужен Python 3.11 или новее. Команды для macOS и Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m uvicorn app_final:app --reload
```

Документация API: http://127.0.0.1:8000/docs

Для запуска без автоматической перезагрузки:

```bash
python -m uvicorn app_final:app
```

## Проверка работы

```bash
curl http://127.0.0.1:8000/health
curl http://127.0.0.1:8000/version
```

Ожидаемые ответы: `{"status":"ok"}` и `{"version":"0.1.0"}`.
Uvicorn выводит сообщения о запуске и HTTP-запросах в терминал.

## Проверка пароля

`GET /criteria` возвращает правила проверки. `POST /check` принимает JSON с полем `password`:

```bash
curl -X POST http://127.0.0.1:8000/check \
  -H 'Content-Type: application/json' \
  -d '{"password":"password123"}'
```

Ответ содержит число выполненных критериев (`score` из `max_score`),
уровень (`weak`, `medium`, `strong`), результаты проверок и рекомендации.
Сам пароль в ответ не включается и не сохраняется.

Проверяются длина от 12 символов, строчные и заглавные буквы, цифры,
специальные символы, отсутствие трёх одинаковых символов подряд,
последовательностей из четырёх символов и совпадений с небольшим списком
распространённых паролей. Последовательности проверяются по латинскому алфавиту,
цифрам и строкам клавиатуры QWERTY в обоих направлениях, без учёта регистра.

Каждая пройденная проверка даёт один балл. Уровень `strong` означает 8 из 8.
Пароль короче 8 символов, из списка распространённых или с оценкой ниже 5
получает `weak`. Остальные получают `medium`.

Допустимая длина входного пароля - от 1 до 256 символов. Пробелы по краям
не удаляются. Некорректный запрос возвращает HTTP 422.

## Генерация пароля

`POST /generate` принимает длину пароля:

```bash
curl -X POST http://127.0.0.1:8000/generate \
  -H 'Content-Type: application/json' \
  -d '{"length":20}'
```

Ответ содержит пароль в поле `password` и его длину в поле `length`.
Допустимая длина - целое число от 12 до 128. Если передать `{}`,
используется длина по умолчанию. Некорректный запрос возвращает HTTP 422.

Для генерации используется стандартная библиотека `secrets`.
Пароль содержит строчные и заглавные латинские буквы, цифры и специальные
символы в случайном порядке. Если он не проходит все проверки `/check`,
генерация повторяется.

## Тесты

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -v
```

Тесты проверяют служебные маршруты, оценку паролей, генерацию и ошибки
входных данных. Запускать сервер отдельно не нужно.

## GitHub Actions

Workflow `.github/workflows/ci.yml` запускает тесты при `push` и `pull_request`
на Ubuntu с Python 3.14. После успешных тестов создаётся artifact
`password-service` с кодом приложения, тестами, зависимостями, README
и `.env.example`.

Результат проверки и логи шагов доступны во вкладке Actions репозитория.
Чтобы скачать artifact, откройте успешный запуск и найдите раздел Artifacts.

## Настройки

Переменная окружения `DEFAULT_PASSWORD_LENGTH` задаёт длину генерируемого
пароля по умолчанию. Значение по умолчанию - 16, допустимый диапазон - от 12 до 128.

```bash
export DEFAULT_PASSWORD_LENGTH=20
python -m uvicorn app_final:app
```

Пример настройки есть в `.env.example`. Чтобы использовать файл `.env`:

```bash
cp .env.example .env
set -a
source .env
set +a
python -m uvicorn app_final:app
```

## Диагностика

Uvicorn выводит в терминал сообщения о запуске и HTTP-запросах:
метод, путь и код ответа.

- Если сервер не запускается, проверьте, что `DEFAULT_PASSWORD_LENGTH` содержит
  целое число от 12 до 128.
- Если порт занят, запустите сервис с `--port 8001` и используйте этот порт в запросах.
- При HTTP 422 проверьте тело запроса в `/docs`.
- Чтобы проверить доступность сервиса, откройте `/health`, а текущую версию - `/version`.
